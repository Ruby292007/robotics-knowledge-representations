⚙️ Robot Decision Process

How the robot converts a command into a safe physical action.

1

Interpret the Command

The robot receives "Fetch a cup" or "Fetch a plate".

2

Search Knowledge Base

The robot searches its stored object knowledge.

3

Retrieve Object Frame

Shape, location, fragility, grasp and carry information are retrieved.

4

Navigate

The robot travels to the stored object location.

5

Apply Correct Grasp

The robot selects the appropriate grasping method.

6

Carry Safely

The robot carries the object according to its properties.

7

Deliver to User

The requested object is safely delivered.

⚖️ Scripts vs Frames

Comparison of knowledge representation techniques

📜 Scripts

  • ✔ Easy to model repeated actions
  • ✔ Represents action sequences
  • ✔ Simple to understand
  • ✖ Poor at object-specific knowledge
  • ✖ Less flexible for different objects

🧠 Frames

  • ✔ Store detailed object properties
  • ✔ Support intelligent reasoning
  • ✔ Support inheritance
  • ✔ Flexible decision-making
  • ✔ Easy to extend with new objects

⚠️ Risks of Incomplete Representation

Why detailed knowledge is important

✋

Missing Handle

The robot may grasp the cup incorrectly.

💥

Missing Fragility

Excessive gripping can cause breakage.

📍

Missing Location

Searching increases time and battery consumption.

💧

Missing Carry Method

Incorrect orientation may cause spills.

🍽️

Missing Grasp Point

A plate may slip and break.

🔋

Unnecessary Search

Poor knowledge wastes robot resources.

✨ Advantages of Frames

Benefits of detailed object representation

👁️ Better Recognition

Stores meaningful object properties.

🧠 Intelligent Reasoning

Helps select appropriate actions.

➕ Easy Extension

New objects can easily be added.

🛡️ Improved Safety

Handling instructions reduce damage.

🎯 Conclusion

Frames capture detailed knowledge about each object's properties and handling requirements.


A script describes the general sequence of fetching an object, while frames allow the robot to distinguish between the correct handling of a cup and a plate.
